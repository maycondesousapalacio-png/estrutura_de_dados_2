    Como jogar

    1. Leve a caixa pela árvore: menor vai para a esquerda, maior para a direita (setas ← →).
    2. Cada rua percorrida gasta 1 de combustível. Árvore alta = rotas longas.
    3. Se algum nó ficar com FB = ±2, escolha a rotação certa (teclas 1–4).
    4. Errou a rotação? Perde uma vida e a árvore fica torta até alguém consertar.
