# Sobre a Disciplina

A disciplina de Estrutura de Dados 2 tem como objetivo aprofundar os conceitos de estruturas de dados não lineares e algoritmos avançados, abordando tópicos como:
Árvores (AVL, Rubro-Negra, B, Trie, etc.)
Grafos (representações, buscas, caminhos mínimos, árvores geradoras)
Tabelas Hash e funções de dispersão
Algoritmos de ordenação avançados (QuickSort, MergeSort, HeapSort)
Análise de complexidade de algoritmos
Estruturas de dados para problemas específicos (filas de prioridade, union-find, etc.)
